# 🌍 TraceDonate — Transparent Donation Management System

TraceDonate is a web-based donation management platform designed to improve transparency and trust in humanitarian giving. It aims to connect donors with charitable projects and help users understand how donations can support people in need.

## ✨ Project Overview

The goal of TraceDonate is to make online donations more transparent, accessible, and organized through a centralized web application.

## 🚀 Technologies Used

- **Frontend:** React
- **Backend:** Node.js and Express.js
- **Database:** MySQL

## 🎯 Project Goals

- Provide a platform for managing donation-related activities.
- Help users discover and support humanitarian initiatives.
- Improve transparency in the donation process.
- Build an accessible and user-friendly web experience.

## 🛠️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js and npm
- MySQL
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/soukainaaitmouloud/TraceDonate.git
   ```

2. Open the project folder:

   ```bash
   cd TraceDonate
   ```

3. Install the backend dependencies:

   ```bash
   cd backend
   npm install
   ```

4. Configure your backend environment variables in a local `.env` file. Use the variable names required by your project, and never commit passwords, API keys, or other secrets to GitHub.

5. Start the backend using the script defined in `backend/package.json`, for example:

   ```bash
   npm start
   ```

6. Open a separate terminal, navigate to the frontend folder, and install its dependencies:

   ```bash
   cd frontend
   npm install
   ```

7. Start the frontend using the script defined in `frontend/package.json`.

## 🔐 Security

- Keep database credentials and secret keys in environment variables.
- Do not upload `.env` files or other files containing sensitive information.
- Use secure authentication practices when deploying the application.
